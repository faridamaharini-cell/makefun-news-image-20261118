# 18 November 2026 in one image

A program that writes one image summing up Wednesday 18 November 2026 world news — 27 real stories on a single front page — to `entry.png`. Built for the make.fun news-image-20261118 bounty.

## Run it

Run the program with the output directory pointed at a temporary folder; it copies the finished front page there as `entry.png`:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/news-image-20261118-out node main.ts
```
