# 18 November 2026 in one image

A program that writes one image summing up Wednesday 18 November 2026 world news — 42 real stories on a single front page: 13 illustrated cards, briefs 14–42, a world map and a DATE CHECK — to `entry.png`. Built for the make.fun news-image-20261118 bounty. This is the v2 entry (supersedes v1's 27-story page).

## Run it

Run the program with the output directory pointed at a temporary folder; it copies the finished front page there as `entry.png`, verifying the JPEG marker, the 1 MiB size limit and the SHA-256 on the way:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/news-image-20261118-out node main.ts
```
